# Daily-Activity-Analyzer
📊 Daily Activity Analyzer (Java)
📈 A console-based Java application to analyze daily activity data using core programming concepts.

-----------------------------------------------------------------------------
🚀 Features
📥 Takes user input for number of days and activity values
🧮 Stores data using arrays for structured processing
🔁 Uses loops to iterate through daily records
📊 Calculates total and average activity
🔝 Identifies the highest activity day
📉 Provides basic data analysis output in console
-------------------------------------------------------------------------------
🧠 Concepts Used
Arrays
Loops (for loop / enhanced for loop)
Conditional statements (if-else)
Scanner class (input handling)
---------------------------------------------------------------------------
🖥️ Working Flow
User enters number of days
Inputs activity values for each day
Program processes data using arrays and loops
Displays analysis results like total, average, and max activity
------------------------------------------------------------------------------------
💡 Outcome
Helps understand how to store and analyze numeric data in Java
Builds strong foundation in loops, arrays, and logic building
Simulates basic real-world data tracking system
